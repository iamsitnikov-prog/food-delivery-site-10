# Обложки статей блога

Каждая статья получает свою картинку 1200×630 для соцсетей, мессенджеров и
Яндекс Бизнеса (og:image). Стиль: вариант A, утверждён Юрием 22.11.2026.
Слева рубрика, короткий заголовок и подзаголовок, справа карточка с главной
цифрой или пунктами статьи.

## Новая статья

1. Добавьте запись в `covers.json`: `slug`, `title` (коротко, до 3 строк),
   `sub` и `card`. Цифры берите только из самой статьи.
   Типы карточек: `bars` (сравнение полосками, `w` в процентах от самого
   большого), `lines` (строки и итог), `stat` (одна большая цифра),
   `check` (пункты с галочками), `steps` (шаги по номерам),
   `swap` (было и стало), `split` (можно и нельзя).
2. `node scripts/blog-covers/gen.cjs <slug>`
3. Посмотрите картинку `public/og/blog/<slug>.jpg` глазами.
4. `npm run split-data`, затем коммит.

Если обложки нет, страница статьи берёт общую картинку сайта.
